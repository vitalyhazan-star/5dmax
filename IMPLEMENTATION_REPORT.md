## 📋 ЧТО НУЖНО ВСТАВИТЬ РУКАМИ

### 1. API-ключи и настройки (.env)
```bash
cp .env.example .env
# Заполнить:
YOOKASSA_SHOP_ID=...
YOOKASSA_SECRET_KEY=...
CRYPTOBOT_API_TOKEN=...
TELEGRAM_MANAGER_USERNAME=...
GEMINI_API_KEY=...
APP_URL=...
```

### 2. Финальные цены
Отредактировать `src/config/pricing.ts`:
```typescript
export const PRICING_EXPERIMENTS: Record<Currency, PricingExperimentConfig> = {
  RUB: {
    monthly: 790,  // ← ваша цена
    yearly: 5990,
    lifetime: 12900,
    // ...
  },
  // ...
};
```

### 3. Логин админки
Создать `/admin` роут в server.ts:
```typescript
const ADMIN_LOGIN = process.env.ADMIN_LOGIN || 'admin';
const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || 'changeme';
```

### 4. Тексты бренда
Пройти по файлам и заменить:
- `src/components/PaywallModal.tsx` — тексты пейволла
- `src/components/DownsellModal.tsx` — даунселл-оффер
- `src/components/OracleChat.tsx` — системный промт Оракула
- `src/config/productConfig.ts` — убрать клише
